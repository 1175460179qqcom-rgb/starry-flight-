# starry-flight-
Starry Flight Player 是基于 PyQt5 的 Windows 本地音乐播放器，纯本地免费无付费。支持 mp3/flac/wav 等七种格式，顺序/单曲/随机播放、变速、预加载、播放历史。提供七种界面语言即时切换、本地 LRC 与免费在线歌词、多主题皮肤、桌面歌词、均衡器、频谱、收藏歌单、托盘控制与自定义快捷键

**功能清单摘要**

1. **定位**：PyQt5 Windows 本地音乐播放器，纯本地免费、无付费/VIP/云账号，单文件主程序 + config.json 配置。
2. **核心播放**：mp3/flac/wav/ogg/m4a/wma/ape 七种格式；librosa→pydub→soundfile 三级解码兜底，sounddevice 输出；播放/暂停、上下首、进度跳转、音量记忆；顺序/单曲/随机三模式；0.5x–2.0x 变速；预加载下一首；播放历史 50 首；失败自动跳过；mutagen 标签读取；递归目录扫描；托盘切歌通知。
3. **界面主题**：无边框自定义标题栏、原生八向边缘缩放、F11 全屏；cyberpunk/forest 两套内置主题、界面圆滑度可调、支持导入本地 QSS 皮肤；歌单栏可收起/拖宽并记忆。
4. **多语言**：简体中文/English/日本語/Français/Deutsch/한국어/Русский 七语言，运行时即时切换，含首次启动语言选择；歌词与歌名不翻译，公告随语言切换。
5. **歌词**：本地 `.lrc` + `.trans.lrc`（自动探测 4 种编码）；原文/译文/双语三模式；霓虹/彩虹高亮特效；字号/行距/字体/偏移可调；歌词背景支持主题渐变/图片/GIF/视频（OpenCV 循环）/纯色，透明度可调。
6. **桌面歌词**：独立置顶窗口、可拖拽记忆位置；9 种颜色模式、字号 16–48、6 种字体。
7. **设置项**：列表/歌词/外观/语言/播放/通知/快捷键/在线歌词/均衡器（5 段）/频谱样式/皮肤导入等，全部持久化。
8. **快捷键**：Space 播放暂停、方向键切歌、F11 全屏；播放/暂停、上下首可自定义捕获按键，可开关。
9. **其他特色**：系统托盘（显示/控制/退出）、收藏、多歌单管理、列表实时搜索、128 段实时频谱、睡眠定时器（5–60 分钟）、个人主页（昵称/头像）、公告栏、隐私政策首启确认、异常日志不闪退。
