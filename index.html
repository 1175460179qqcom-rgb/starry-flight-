FEATURES

核心功能

从播放到歌词，从主题到桌面歌词，每一个细节都为本地音乐体验而设计。

🎵

七种音频格式

支持 MP3 / FLAC / WAV / OGG / M4A / WMA / APE 无损与常见格式，librosa 与 FFmpeg 多级解码兜底，开箱即听。

⏯️

播放模式 · 变速 · 预加载

顺序 / 单曲 / 随机三种模式一键切换；0.5x–2.0x 十六档变速；后台预加载下一首，切歌秒开，播放历史自动记录最近 50 首。

🌐

七语言界面

简体中文 / English / 日本語 / Français / Deutsch / 한국어 / Русский，设置内一键切换即时生效，首次启动可选语言。

📜

本地 LRC 与桌面歌词

自动加载歌曲同名 .lrc 与 .trans.lrc，多编码兼容；霓虹 / 彩虹高亮、三档显示模式；独立置顶桌面歌词，颜色字号字体自由调节。

🎨

双主题 · 自定义皮肤

内置赛博朋克与森林墨绿两套主题，界面圆滑度可调；支持导入本地 QSS 皮肤文件，打造属于你的配色。

📊

均衡器 · 实时频谱

五段均衡器调节；128 段实时频谱可视化，颜色模式与方块样式随心切换，跟着节拍律动。

❤️

收藏与歌单

列表右键一键收藏；自由创建多歌单、把歌曲加入任意歌单；顶部搜索框实时过滤，曲库再多也不怕。

⌨️

托盘 · 快捷键 · 睡眠定时

系统托盘常驻控制，切歌桌面通知；自定义播放 / 上一首 / 下一首快捷键；5–60 分钟睡眠定时，伴你入眠。

💼

单文件便携

一个 exe 即完整播放器，免安装绿色运行；配置与播放历史统一存放于本地 config.json，随身拷贝即迁移。

ABOUT

关于 StarryFlightPlayer

StarryFlightPlayer 由独立开发者维护，诞生于"本地音乐值得被认真对待"的信念：没有广告、没有会员墙，只有流畅的播放、精美的歌词与纯粹的私人音乐空间。

我们相信音乐播放器应该轻量、快速、诚实。欢迎在 GitHub 上提交 Issue 与建议，一起让 StarryFlightPlayer 变得更好。
